# Dog Burger & Café (projeto fictício)

> **Aviso:** site 100% fictício criado para portfólio. Nome, endereço
> (Av. Fictícia, 621 — Porto Fictício/EX), telefone `(00) 90000-0007`,
> WhatsApp, preços, avaliações e mapas são inventados. Nenhum dado é real
> e não representa nenhuma empresa.

🌐 **Demo no ar:** https://dog-burger-site.vercel.app

Site de hamburgueria artesanal fictícia (Next.js): hero, especialidades,
depoimentos, FAQ, localização e pedido via WhatsApp. Admin opcional via
variáveis de ambiente (`ADMIN_PASSWORD`, `WHATSAPP_NUMBER`).

## Stack

- Next.js 16 + React 19 + Tailwind + Framer Motion/Lenis/GSAP
- SEO: metadata, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`

## Rodar local

```bash
npm install
npm run dev
```

Hospedado na Vercel. Push na branch principal = redeploy.
